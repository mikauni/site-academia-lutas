# Site – Academia de Lutas Márcio Vargas

## Sobre o projeto

Este projeto consiste no desenvolvimento de um site institucional para a Academia de Lutas Márcio Vargas, com o objetivo de fortalecer sua presença digital e apresentar seus serviços de maneira profissional, moderna e acessível.

## Objetivo

Criar uma plataforma que facilite o acesso às informações da academia, apresente suas modalidades e aproxime novos alunos do espaço, proporcionando uma experiência de navegação simples e intuitiva.

## Desenvolvimento

O projeto foi desenvolvido com foco em:

- Design moderno e responsivo.
- Experiência do usuário (UX).
- Interface intuitiva e organizada (UI).
- Apresentação dos serviços e modalidades.
- Facilidade de navegação e acesso às informações.

## Tecnologias
